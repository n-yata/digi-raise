# 決定事項ログ: 操作時の効果音追加

## D1: 実装方式は Web Audio API 合成（音声アセットなし）
- 決定: mp3/ogg 等のバイナリアセットを持たず、`OscillatorNode` + `GainNode` でその場合成する。
- 理由: PWA 軽量性、外部 URL/バイナリのハードコード回避（セキュリティ）、8bit レトロ世界観との親和性。
- シャビ承認: 「合成音・全操作（推奨）」を選択。

## D2: 失敗操作では固有音を鳴らさない
- 決定: ご飯（満腹で `お腹いっぱい` early return）など、操作が成立しなかった場合は効果音を鳴らさない。
- 影響: 孵化直後の卵/ベイビーは満腹度が高く、ご飯ボタンを押しても無音になりうる。これは仕様。
- 補足: verify 中、最初に満腹の卵でご飯を試すと無音に見えるため、混乱を避ける場合は将来やわらかいエラー音を検討（今回スコープ外）。

## D3: 音量の底上げ（verify 中の調整）
- 背景: 初期実装（peak gain 0.18〜0.2 / 最短 60ms）は環境によって聞こえにくかった。
- 決定: `MASTER_GAIN = 1.5` を導入し peak を約 0.51 まで底上げ（歪み防止に 0.9 上限クランプ）。エンベロープに短い保持区間を追加し、tap を 0.11s に延長。
- 検証: 実機で `playSound` が osc を生成し AudioContext が running であることを確認済み。

## D4: ミュート設定の保存先は localStorage
- 決定: ゲームセーブ（IndexedDB）とは独立した端末ローカル UI 設定として `localStorage('digi-raise:muted')` に保存。
- 理由: 同期的に読める／ゲーム進行データではない／クラウド同期対象にしない。
- 安全性: 保存値は '1'/'0' のみ。汚染値は安全側（音あり）にフォールバック。

## メモ: lint 不能の既存課題
- `npm run lint` はスクリプトに eslint を参照するが devDependencies に eslint が無く実行不可。本スプリントでは tsc（build）で型品質を担保。恒久対応は別途検討。
