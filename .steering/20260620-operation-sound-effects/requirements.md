# 要求: 操作時の効果音追加

## 背景・目的

デジレイズには現在、操作に対する音のフィードバックが一切ない。タップやアクション（ごはん・遊び等）に効果音を付けることで、操作の手応え・気持ちよさを高め、レトロ育成ゲームらしい体験を強化する。

## 今回の要求内容

- ユーザー操作時に効果音を鳴らす。
- 実装方式は **Web Audio API による合成音**（8bit 風）。音声バイナリアセットは持たない。
  - 理由: PWA の軽量性維持、外部アセット/URL のハードコード回避（セキュリティ）、レトロ世界観との親和性。
- 対象は「全操作」。
  - 共通: ボタンタップ全般（汎用クリック音）
  - アクション別: ごはん / 遊び / トレーニング（成否） / おやすみ・おはよう / 進化 / 卵ふ化 / バトル開始・勝敗 など主要操作に固有音を割り当てる。
- ミュート切り替えを用意する（設定の永続化込み）。初期状態は ON（音あり）。
- ブラウザの自動再生制限に対応する（初回ユーザー操作で AudioContext を解放）。

## スコープ外

- BGM（背景音楽）の追加。
- 音量の段階調整 UI（今回は ON/OFF のみ）。
- 音声ファイルアセットの導入。

## 受け入れ基準

- 主要操作で固有の効果音が鳴る。
- ミュート切替で全効果音が無効化され、リロード後も状態が保持される。
- 自動再生制限により初回操作で確実に音が出る。
- 既存のテスト・lint・build がすべて通る。

## ゲームデザイン上の確認事項

- 効果音はゲームバランス（EXP・成長値・ダメージ計算等）に影響しない演出要素。
- 音の有無・種類は UX 演出であり、進化条件や数値ロジックは一切変更しない。
