# 決定事項ログ: 食事・遊びアクション演出の強化

## 2026-06-20

### アイテムの種類（ゲーム内容の追加だが演出のみ・バランス不変）
- 食べ物 3 種: 肉 / りんご / おにぎり
- 遊び道具 3 種: ボール / ディスク（フリスビー）/ ぬいぐるみ
- いずれも見た目（ドット絵）のみ。満腹度・幸福度などの効果量は一切変えない。
- ランダム選択でどれが出るかは結果に影響しない（演出差のみ）。

### ビジュアル表現
- 既存 `PixelSprite` と同じ文字グリッド + パレット方式のドット絵で描画し、世界観を統一。
- アイテムは小さめ（16×16）グリッド。`ItemSprite` は viewBox をグリッド寸法から算出する。

### スキップ仕様
- 画面（クリーチャー表示エリア）タップで食事・遊び演出を即終了。
- トレーニング（ミニゲーム）は対象外。

### アイテムは「絡む動き」にする（シャビ指摘で方針修正）
- 当初はアイテムをクリーチャー脇に静止表示するだけ → 「食べる/遊ぶアクションが無くセンスがない」と指摘。
- 修正方針: アイテムがクリーチャーと絡んで動く。
  - 食事: 食べ物が口元へ運ばれ、数口かじられて段階的に縮小して消える（`foodEat`）。
  - 遊び: 道具ごとに動きを変える。ボール=弾む（`toyBall`）/ ディスク=回転して飛ぶ（`toyDisc`）/
    ぬいぐるみ=ふわふわ抱える（`toyTeddy`）。
- 演出を見せきるため再生時間を 1200ms → 1600ms に延長。これは演出尺のみで、満腹度・
  幸福度などの効果量・時間更新サイクルには影響しない（タップでスキップ可）。

### 不変条件
- `gameLogic.ts` の数値計算・時間更新サイクルは変更しない。
