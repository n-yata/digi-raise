---

## 1. 背景

- クリーチャー本体は 32×32 ドット絵スプライトへ全面移行済み（commit 66189ca）。
  一方、卵（stage 0）だけは `EggBody.tsx` の滑らかな CSS グラデーション表示のままで、
  レトロな世界観から浮いている。
- 「タップして生まれる！」ボタンの削除・自動ふ化は `20260619-egg-auto-hatch` で実装済み。
  ただし現状は `canEvolve` 成立と**同時に即ふ化**するため、卵がメイン画面にほぼ映らず
  いきなり進化演出へ遷移してしまう。

## 2. ゴール

1. **卵表示のアナログ（ドット絵）化** — クリーチャー本体と同じ 32×32 ドット絵で卵を描画し、
   レトロな世界観へ統一する。卵はタイプカラーで色づけする。
2. **数秒後の自動ふ化** — はじめからプレイ時、メイン画面に卵を一定時間（3秒）見せてから
   自動でふ化させる。タップ操作は不要のまま。

## 3. スコープ

### 含むもの
- 卵のドット絵スプライト新規追加（`src/components/creatures/pixel/egg.ts`）
- `CreatureSprite.tsx` を卵もドット絵レンダラ（`PixelSprite`）で描画するよう変更
- `App.tsx` の stage 0 自動ふ化に 3 秒ディレイを追加
- 不要となった `EggBody.tsx` の削除
- 永続ドキュメント（architecture.md / repository-structure.md）の EggBody 記述更新

### 含まないもの
- minAge の変更（0 のまま維持）
- ベイビー以降の進化フロー変更
- ふ化前の卵を揺らす等の追加演出（今回は静止ドット絵のみ）

## 4. 受け入れ条件

- [ ] 卵が 32×32 ドット絵（タイプカラー）で表示される
- [ ] はじめから開始後、メイン画面に卵が約3秒表示されてから自動ふ化し進化演出へ遷移する
- [ ] 卵ステージで「タップして生まれる！」ボタンが表示されない（既存挙動を維持）
- [ ] ベイビー以降の進化はタップが必要なまま（変更なし）
- [ ] `npm run build` / `npm run lint` / `npm run test:run` が通る
- [ ] クルトワ（security-engineer）レビューで Critical/High なし
