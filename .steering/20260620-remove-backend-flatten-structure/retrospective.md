## 学んだこと

**技術的な学び**:
- `git mv` でディレクトリを移動すると、git は rename 100% として扱うため履歴が追跡される。コード変更ゼロでリネームを表現できる
- `node_modules/` は git 管理外なので `git mv` の対象にならない。移動後は `npm install` を再実行することで worktree ルートに再構築される
- `package.json` に記載のない CLI ツール（今回は `eslint`）がスクリプトで使われていると、`npm install` 後に実行できない。依存関係の明示が重要

**プロセス上の改善点**:
- worktree でのファイル移動 → ビルド確認 → セキュリティレビュー → コミットの順序が明確に機能した
- `git diff --stat HEAD` で変更サマリーを確認してからクルトワに渡すと、レビューの焦点が絞られて効率的
