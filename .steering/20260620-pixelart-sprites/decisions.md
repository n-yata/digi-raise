# 決定事項ログ — クリーチャーのドット絵化

## D-001 モザイクフィルタ方式を却下、本物のドット絵スプライトを新規作成
- **背景**: クリーチャーがSVG（楕円・円ベースのベクター）化されレトロなドット絵感が失われていた。
- **検討した案**:
  1. SVGに `#retro-pixelate`（feTile + feMorphology）モザイクフィルタをかけてドット絵風に見せる
  2. 32×32グリッドの本物のドット絵スプライトをゼロから新規作成
- **決定**: 案2を採用。案1はドットの目が揃わず汚い「ごまかし」になるためシャビ却下。
- **判断者**: シャビ

## D-002 ドット絵の解像度は 32×32 グリッド
- **決定**: 細かめの 32×32。初代ポケモ/デジモン風の粗さより描き込める。
- **判断者**: シャビ

## D-003 進め方はプロトタイプ先行
- **決定**: まず Fire 1体（成長期 / stage 3）をドット絵化して方向性を確認。
  OKなら設計（バルベルデ）を固め、6タイプ×5ステージへ展開する。
- **判断者**: シャビ

## 実装メモ（プロト段階）
- 汎用レンダラ `PixelSprite`（文字グリッド + パレット → `<rect>` 1セル描画、`shapeRendering="crispEdges"`）。
- `getPixelSprite(type, stage)` で未実装は既存SVG（`DefaultCreatureBody`）にフォールバック → 段階的移行が可能。
- モザイクフィルタ方式（App.tsx の filter defs / index.css の filter）は撤去。
