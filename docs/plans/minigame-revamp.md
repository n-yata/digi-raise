## 概要

トレーニングと遊ぶのミニゲームを刷新する。

| アクション | 現状 | 変更後 |

| トレーニング | タイミングバー（緑ゾーンでタップ） | もぐらたたき |

## 1. トレーニング → もぐらたたき

### ゲーム仕様

- 3x3 グリッドにクリーチャーがランダムに出現
- 制限時間: 8秒
- 出現間隔: 約1秒（出現後0.8秒で消える）
- タップで叩く → スコア+1
- 成功判定: 5匹以上叩けたら成功、4匹以下で失敗

### 報酬（変更なし）

| 結果 | 効果 |
|------|------|
| 成功 | atk/def/spd 各+1〜3, hunger -10, EXP +20 |
| 失敗 | atk/def/spd 各+0〜1, hunger -10, EXP +5 |

### インターフェース（変更なし）

```typescript
// Props は既存と同じ
interface Props {
  creature: Creature
  onResult: (success: boolean) => void
}
```

## 2. あそぶ → 神経衰弱（ミニ版）

### ゲーム仕様

- 2x3 グリッド（6枚カード = 3ペア）
- カードの絵柄: クリーチャーのタイプに応じたアイコン3種（例: Fire → 🔥🌋💥）
- 2枚めくってペアが揃えば消える、揃わなければ裏に戻す
- 成功判定: **8手以内**に全ペアを揃えたら成功、9手以上で失敗
  - 最短3手（全部一発で揃う）、ランダムだと平均9手前後
- 手数 = カードをめくった「2枚1組」の回数

### 報酬（変更あり）

| 結果 | 効果 |
|------|------|
| 成功 | happiness +20, hunger -5 |
| 失敗 | happiness +5, hunger -5 |

- **EXP は付与しない**（シャビ指示）
- `playWithCreature` の引数に `success: boolean` を追加

### インターフェース（変更あり）

```typescript
interface Props {
  creature: Creature
  onResult: (success: boolean) => void  // 既存: onResult: () => void から変更
}
```

### UI構成

│    ペアを見つけよう！    │
│                      │
│    残り: 2ペア  手数: 3 │
│                      │
│   ┌───┬───┬───┐      │
│   │ ? │🔥│ ? │      │
│   ├───┼───┼───┤      │
│   │ ? │ ? │🔥│      │
│   └───┴───┴───┘      │
│                      │
│   楽しかった！🎉       │
