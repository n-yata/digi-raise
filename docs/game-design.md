# デジレイズ ゲームデザイン決定事項

このドキュメントは、実装に影響するゲームデザイン上の意思決定を記録する。
数値変更・新要素追加の際は、シャビの承認を得てからチームに伝える。

**最終更新**: 2026-04-05 (CPUバトルモード追加)

## クリーチャータイプ (6種)

| タイプ | 最終進化名 | 特色 |
|--------|-----------|------|
| 🔥 Fire | エンペラーモン | 連続攻撃特化 |
| 💧 Water | オーシャンモン | 回復+攻撃のバランス型 |
| 🌿 Plant | エデンモン | 持続ダメージ（毒）型 |
| ⚡ Thunder | インドラモン | 行動妨害（麻痺）型 |

| ✨ Light | セラフィモン | 防御バフ型 |

## 進化ステージと条件

| ステージ | 名称 | 進化条件 |
|---------|------|----------|
| 0 | タマゴ | — |
| 1 | ベイビー | タマゴをタップ（即時） |
| 2 | チャイルド | age ≥ 1 |
| 3 | アダルト | age ≥ 3, happiness ≥ 50 |
| 4 | パーフェクト | age ≥ 6, level ≥ 8, atk+def+spd ≥ 40 |
| 5 | アルティメット | age ≥ 12, level ≥ 14, 各ステータス ≥ 20 |

> `age` の単位: 30分ティックごとに +0.5 の累積。表示は `Math.floor(age)` 日。

## 育成アクション

### えさ
- 効果: hunger +30, happiness +5, weight +1（過食時 +3）
- 制限: 睡眠中は不可
- **EXP付与なし（意図的な設計）**

### トレーニング
- 成功: atk/def/spd 各 +1〜3（ランダム）, hunger -10, EXP +20
- 失敗: atk/def/spd 各 +0〜1（ランダム）, hunger -10, EXP +5
- 制限: 睡眠中・空腹（hunger ≤ 0）時は不可

### あそぶ
- 効果: happiness +20, hunger -5, EXP +5
- 制限: 睡眠中・空腹（hunger ≤ 0）時は不可

### ねる
- 睡眠中: HP +5 / 30分（= +10/時間）
- 制限なし

| 条件 | 処理 |
|------|------|
| 毎ティック | hunger -5, happiness -2, age +0.5 |
| 睡眠中 | hp +5 |
| hunger ≤ 0 | hp -5（餓死ダメージ） |
| hp ≤ 0 | 死亡 → タイトル画面へ |

## バトルシステム

### ダメージ計算式

```
baseDamage = attacker.atk * 1.5 - defender.def * (guarding ? 1.6 : 0.8)
typeMod    = TYPE_ADVANTAGE[attacker.type][defender.type]  // 0.8, 1.0, 1.2
spdMod     = attacker.spd > defender.spd ? 1.1 : 0.9
finalDamage = Math.max(1, Math.floor(baseDamage * typeMod * spdMod))
```

### 特殊アクション（special）タイプ別効果

| タイプ | 効果 |
|-------|------|
| Fire | 連続2回攻撃（各ダメージ×0.7） |
| Water | 自己回復（maxHp × 0.2）+ 攻撃 |
| Plant | 毒付与（3ターン、毎ターン最大HP×3%ダメージ） |
| Thunder | 麻痺（次ターン行動不可 50%確率） |
| Dark | 相手のATKを1ターン −30% |
| Light | 防御バフ（自DEF×1.5、2ターン） |

クールダウン: 2ターン

### バトル終了条件

| 条件 | 勝者 |
|------|------|
| いずれかのHP ≤ 0 | 相手プレイヤー |
| 10ターン経過 | HP が多い方（同値: 引き分け） |
| 相手が切断 | 残ったプレイヤー |

### バトル後ステータス反映

| 結果 | 変化 |
|------|------|
| 勝利 | wins +1, exp +(50 + 相手level×5), happiness +20 |
| 敗北 | losses +1, exp +10, happiness -10 |
| 引き分け | exp +25 |

HP はバトル終了時の値を維持する。

### CPUバトルモード（2026-04-05 追加）

オンライン対戦に加え、CPU（コンピュータ）対戦モードを追加。WebSocket不要でオフラインで遊べる。

| 項目 | 設計 |
|------|------|
| CPUクリーチャー生成 | プレイヤーの進化段階・ステータスに合わせて自動調整（±10%変動） |
| CPUのタイプ | プレイヤーと異なるタイプからランダム選択 |
| CPUの名前 | 進化系統テーブルから該当ステージの名前を使用 |
| CPUのアクション選択 | 完全ランダム（attack/guard/special 均等、クールダウン中は attack/guard のみ） |
| バトル報酬 | オンライン対戦と同一（勝利: exp +50+相手Lv×5, happiness +20 等） |
| バトル終了条件 | オンライン対戦と同一（HP≤0 or 10ターン経過） |
| ロビーUI | 「CPU対戦」タブ追加。対戦相手のプレビュー表示、相手の変更（再生成）が可能 |
