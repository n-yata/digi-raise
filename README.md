# デジレイズ / DigiRaise

デジモン風の育成ゲーム PWA です。クリーチャーを育て、進化させましょう。

## 遊び方

1. タイトル画面でクリーチャーの名前とタイプを選択
2. タマゴをタップして孵化させる
3. えさ・トレーニング・あそぶ・ねるで世話をする
4. 条件を満たすと進化する（最終的にアルティメットを目指せ）
5. 放置しすぎると死んでしまう……

## アクション

| アクション | 効果 | 制限 |
|-----------|------|------|
| えさ | hunger +30, happiness +5, EXP +2 | 睡眠中は不可 |
| トレーニング | atk/def/spd +1〜3, hunger -10, EXP +10〜20 | 睡眠中・空腹時は不可 |
| あそぶ | happiness +20, hunger -5, EXP +5 | 睡眠中・空腹時は不可 |
| ねる | 睡眠状態を切り替え (睡眠中は HP が毎時回復) | — |

### タマゴステージ

タマゴ状態ではアクションボタンはすべて無効です。「🥚 タップして生まれる！」ボタンをタップすると孵化してベイビーになります。

### トレーニングミニゲーム

トレーニングボタンを押すとミニゲームが始まります。動くバーの緑ゾーン（35〜65%）でタップすると成功、大きくステータスが伸びます。

## クリーチャータイプ

| タイプ | 最終進化名 |
|--------|-----------|
| 🔥 Fire | エンペラーモン |
| 💧 Water | オーシャンモン |
| 🌿 Plant | エデンモン |
| ⚡ Thunder | インドラモン |
| 🌑 Dark | ルシフェモン |
| ✨ Light | セラフィモン |

## 進化ステージと条件

| ステージ | 名称 | 進化条件 |
|---------|------|----------|
| 0 | タマゴ | — |
| 1 | ベイビー | タマゴをタップ |
| 2 | チャイルド | age ≥ 3, happiness ≥ 50 |
| 3 | アダルト | age ≥ 7, level ≥ 10, atk+def+spd ≥ 60 |
| 4 | パーフェクト | age ≥ 14, level ≥ 20, 各ステータス ≥ 30 |
| 5 | アルティメット | 最終形態 |

## 時間経過

- 30分ごと: hunger -5, happiness -2
- 1時間ごと: age +1、睡眠中は HP +10 回復
- hunger ≤ 0: HP -5/30分（スタベーション）
- HP ≤ 0 → 死亡

## セーブデータ

- データはブラウザの IndexedDB に自動保存されます
- ステータス画面からセーブデータの書き出し・読み込みが可能です（JSON ファイル）

## 技術スタック

- **React 18** + **TypeScript**
- **Vite** + **vite-plugin-pwa** (PWA / オフライン対応)
- **Tailwind CSS**
- **idb** (IndexedDB ラッパー)

## 開発

```bash
npm install
npm run dev      # 開発サーバー起動
npm run build    # プロダクションビルド
npm run preview  # ビルド結果の確認
npm run lint     # Lint チェック
```
